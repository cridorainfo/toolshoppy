What do you need to prepare?

Resize a photo for a form
  1. Read the current form instructions: width, height, file type and maximum KB.
  2. Set the required pixel dimensions in Image Resizer. Keep a copy of the original. Image Resizer (opens in a new tab)
  3. If the file is still too large, compress the resized copy, then check the downloaded dimensions and readability. Image Compressor (opens in a new tab)
Reduce a photo to a KB limit
  1. Choose the maximum size written on the application portal; there is no single limit for all services.
  2. Select your photo, enter the target KB and download the result. Image Compressor (opens in a new tab)
  3. Read the output file size and inspect the face or signature. A smaller file is useful only if it remains clear.
Prepare a PSC or other application photo
  1. Compare the current application notice with the tool preset before using it. Requirements can change.
  2. Choose a preset, position the face inside the crop and export a copy. Government Form Photo (opens in a new tab)
  3. Verify any required name, date, background and file limit against the official notice.
Resize a centre or office portrait
  1. Use this 200×230 pixel portrait only when your separate office workflow asks for those dimensions.
  2. Crop and download a portrait copy. This is not an official UIDAI photo specification. 200×230 Portrait Resizer (opens in a new tab)
  3. Resizing a photo here does not update Aadhaar. Follow UIDAI instructions for enrolment or photo updates at an authorised centre.
Turn document photos into one PDF
  1. Photograph every page clearly, including its edges. Avoid glare and keep text upright.
  2. Add the images, arrange them in the required order and create the PDF. Image to PDF (opens in a new tab)
  3. Open the downloaded PDF and check every page before submitting.
Combine supporting documents
  1. Check whether the portal wants one combined PDF or separate documents.
  2. Add the PDFs in the required sequence and merge them. Merge PDF (opens in a new tab)
  3. Review page order and remove accidental duplicates if necessary. Organize PDF (opens in a new tab)
Reduce a PDF for upload
  1. Check the portal’s file-size limit and retain the original PDF.
  2. Compress a copy and compare the downloaded size with the limit. Some PDFs cannot shrink much further. Compress PDF (opens in a new tab)
  3. Zoom in to check names, numbers, stamps and small text before using the result.
Extract or straighten pages
  1. Select only the pages needed for the application and export a separate copy. Split PDF (opens in a new tab)
  2. Rotate sideways or upside-down pages and download the corrected PDF. Rotate PDF (opens in a new tab)
  3. Check that no required page is missing and that all pages open correctly.

Common questions

What is the Akshaya work desk?

It is a free collection of photo and PDF workflows for Akshaya staff and people preparing documents before visiting a centre. It prepares files; it does not submit government applications.

Is this an official Akshaya service?

No. ToolShoppy is independent and is not affiliated with Akshaya, the Government of Kerala or UIDAI. Use the official service portal or an authorised centre to submit applications.

Are files uploaded, and do I need an account?

The linked photo and PDF tools process selected files in your browser. No signup or payment is required. The site may make ordinary network requests for page assets and consent services; see the privacy policy. Downloaded files remain on your device until you remove them.

Which photo size should I choose?

Use the dimensions, format and KB limit in the current application instructions. A 20 KB or 200×230 preset is not a universal government requirement. Check the final file before submitting.

Are the instructions available in Malayalam?

Yes. This desk has English and Malayalam instructions. Linked tools currently use English controls; their names are shown in both versions so you can find the same tool.
