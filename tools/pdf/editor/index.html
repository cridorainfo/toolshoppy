A PDF editor that stays free at download

ToolShoppy lets you edit and download your PDF without a payment screen. There is no credit card, subscription, free-trial expiry, signup or watermark. The editing features on this page and the resulting download are free.

Edit original text, not just a cover-up

On supported PDFs, select a text object and change its wording. The editor updates that object and saves a new PDF, preserving the document's searchable text and vector artwork. You can also insert text, move or delete objects, add images or a signature image, highlight areas, and rotate pages.

Font matching with clear limits

The editor reuses the selected PDF font where character coverage can be verified. A PDF may contain only part of a font. If you need missing letters, load the full TTF font from your device or choose a replacement. Scans, complex scripts, grouped text and automatic paragraph reflow require capabilities beyond this editor. Unsupported original content is preserved.

Highlights and rectangles are annotations, not secure redaction. Do not use a shape to hide sensitive content. Deleting a selected object removes that object; it is not a document-wide sanitization service.

Free PDF editor: questions answered

Is the PDF editor really free to download from?

Yes. Editing and downloading your edited PDF are both free. ToolShoppy does not ask for payment, a subscription, an account or an email address at export. No watermark is added.

Can I edit the actual text in a PDF?

Yes, for supported text objects. Click a text line, change its wording and apply the edit. The original text object is updated rather than covered with a white box. Export preserves searchable text and vector content.

Will the original PDF font be preserved?

The editor reuses the selected text's PDF font when its characters can be verified. Embedded subset fonts may not contain new letters. You can load a full TrueType font locally or explicitly select a replacement. Fonts are never silently substituted by the editing controls.

Can I edit scanned PDFs or reflow paragraphs?

Scans contain images rather than editable text. You can add text or use the Image OCR tool to extract wording. Automatic OCR reconstruction, paragraph reflow, complex-script shaping and editing text inside grouped objects are not supported.

Are my files uploaded?

No. PDF processing runs in your browser. Your PDF and any font or image you choose stay on your device.

Are there file limits?

This browser editor accepts PDFs up to 40 MB and 1,000 pages. Undo history is bounded to protect browser memory. These are technical limits, not a paid tier.
