Frequently asked questions

Does this detect headings automatically?

Yes. Lines with a noticeably larger font size than the body text are converted into # or ## Markdown headings based on relative size.

Will this work on scanned PDFs?

No — this extracts real embedded text. A scanned/image-only PDF has no text layer to extract; use OCR PDF instead to make it searchable first.

Is my PDF uploaded to a server?

No. Conversion uses PDF.js entirely inside your browser — your file never leaves your device.
