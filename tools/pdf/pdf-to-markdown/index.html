How PDF to Markdown works

PDF.js reads the text and the font size of each line. Lines with a noticeably larger font than the body text become Markdown headings (# or ##), and the remaining text becomes paragraphs.

You can insert a separator between original pages, preview the result, copy it, or download a .md file. It only works on PDFs that contain real text. Complex layouts such as multi-column pages may read in a different order than a human would.

Frequently asked questions

Does this detect headings automatically?

Yes. Lines with a noticeably larger font size than the body text are converted into # or ## Markdown headings based on relative size.

Will this work on scanned PDFs?

No — this extracts real embedded text. A scanned/image-only PDF has no text layer to extract; use OCR PDF instead to make it searchable first.

Is my PDF uploaded to a server?

No. Conversion uses PDF.js entirely inside your browser — your file never leaves your device.
