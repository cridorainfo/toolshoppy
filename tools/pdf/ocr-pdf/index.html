Frequently asked questions

What does OCR PDF actually produce?

A new PDF that looks identical to your scan but has an invisible text layer behind it, so you can select, copy, and search the text in any PDF reader. You also get the raw extracted text as a .txt file.

How long does OCR take?

The first run downloads a small on-device OCR model (about 20MB) once, then it's cached. Each page takes a few seconds to process, so large PDFs take longer — progress is shown per page.

Is my PDF uploaded to a server?

No. OCR runs fully on-device using PaddleOCR compiled to WebAssembly — your file and its content never leave your browser.
